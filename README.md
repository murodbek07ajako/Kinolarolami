# KinoBot

## Ishga tushirish (bepul, Render)
1. @BotFather'dan token oling, @userinfobot'dan o'z ID'ingizni bilib oling.
2. Bu papkani GitHub'ga yuklang.
3. render.com → New → Blueprint → repozitoriyni tanlang.
4. Environment: BOT_TOKEN, ADMIN_IDS. WEBAPP_URL'ni hozircha bo'sh qoldiring.
5. Deploy bo'lgach, Render bergan manzilni (https://....onrender.com) WEBAPP_URL ga yozing va qayta deploy qiling.
6. uptimerobot.com'da shu manzilning /health sahifasini har 5 daqiqada tekshirishga qo'ying (bot uxlab qolmasligi uchun).
7. Botga /admin yozing.

Muhim: bepul hostingda fayl tizimi qayta deploy'da tozalanadi. Har kuni /backup qiling.
